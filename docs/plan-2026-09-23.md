## B. 計畫（七節，對主人那七件）

### B1. 新集管道（把第 3 步腳本化）

**做什麼**：把「Opus 一次做完」變成一支可排程的腳本。機械前處理（OpenCC `s2twp`、全形標點、

（`breaks`／`headings`／`quotes`／`ads`／`fixes`）**＋**摘要與立場 JSON → 程式拼回
`structured.md`。模型碰不到正文，一字不改閘門因此必然成立。>70 分鐘切兩次呼叫。

排程走 launchd（`docs/operating-notes.md` 的規矩）。票：RF-1126、RF-1128。

**需要主人給的**：無（`ANTHROPIC_API_KEY` 已在 `~/.ryvn-finance/env`，先確認 key 名再說缺）。
**預估工時**：前處理＋拼回＋閘門 6 h；batch 客戶端 2 h；排程與 Discord 一行 2 h。**≈10 h。**

### B3. UI/UX（個股列表、個股頁、搜尋頁）

程式與資料裡看得到的缺陷，逐條附證據。修法一律照 Medium 拍板
（單欄 ≤680px、無卡片、無陰影、無彩色框、不出現任何內部標籤）。

**個股列表 `/ticker/`**

1. **「1 集 · 0 次」**：`mention_total` 是 `mentions.csv` 的 `mention_count` 加總，
   別名掃描補進來的檔一律 0。今天 **CRM、CRWD、ORCL、3376、3661 五檔顯示「1 集 · 0 次」**，
   而 NVDA 是「5 集 · 3 次」（次數比集數少）。讀者看到的是壞掉的數字。
   **修**：站上的「次」改成**實際標到的句子數**（`blocks` 裡該檔的 marks 數，build 時算好），兩邊同一個口徑。
2. **排序等於沒排序**：`tickers.json` 依 `episode_count` 遞減、同分用**代號字母**（`build-content.mjs:692`）。
   6 集的資料裡 14 檔並列 1 集，於是版面是 ASML、AVGO、BABA、CRM… 的字母表。
   **修**：同分改用 `last_seen` 遞減（最近被講到的在上面），日期印在右邊。
3. **看不出他講了什麼**：列表只有名字、代號、集數、次數，**沒有立場**。
   **修**：每一列右邊加一個立場 icon 列（沿用 `StanceIcon`，紅多綠空，無文字），與集數頁 chip 同一套。
4. **US／TW 兩個 `<h2>` 分組把 23 檔切成 18＋5**，沒有回到頂端或跳到分組的路。23 檔不痛，100 檔會痛。
   **修**：暫不動；回補後超過 60 檔再加一列「美股｜台股」文字 tab（Medium 的 text tab，不是按鈕）。

**個股頁 `/ticker/<代號>/`**

5. **5 檔的 OG 圖是 404**：`app/ticker/[symbol]/page.tsx:39` 指向 `/og/ticker-<代號>.png`，

   `scripts/build-og.mjs` 會產所有檔，只是最後幾次只跑了 `npm run content` 沒跑 `npm run og`。
   **修**：`scripts/check-render.mjs` 加一條：每一個 ticker／episode 頁引用的 OG 檔必須存在，不存在就紅。
6. **mixed 在圖上被吃掉**：`marks` 用 `stancesOf(r)[0]`（`page.tsx:53`），
   同一集看多又看空的集數在價量圖上只留一個方向 —— 而首頁 chip 是雙向 icon，兩邊不一致。
   **修**：`Mark` 帶 `stances[]`，`PriceChart` 畫雙向 marker。
7. **漲跌資料算好了卻沒用**：`timeline[].perf`／`px_1d`／`px_5d`／`px_21d` 在 `tickers.json` 裡是滿的，

   **修**：每一列底下一句引用（serif、灰、一行截斷），點進去跳到那一句（`first_anchor` 已經在集數 JSON 裡）。

**搜尋 `/search/`**

9. **搜不到內容**：索引只有 **29 筆**（6 集 ＋ 23 檔），`sub` 還自己寫著「逐字稿不在本站，搜不到內文」——

   **修**：把 `key_points` 與 `summary_answer_first` 加進索引（每集 10–12 筆重點 → 約 70 筆），

   要全文再談 pagefind 之類的靜態索引。

    **修**：改用 `e.site_title`。
11. **`sub` 出現內部詞**：「抽到 N 檔」的「抽到」是我們的 pipeline 用語。**修**：改成「提到 N 檔」。
12. **沒有 `?q=`**：搜尋字串不進網址，分享不了、也沒有 SEO。
    **修**：`useSearchParams` 讀初值、輸入時 `replaceState`（靜態輸出可行，不影響 export）。

**檔**：`app/ticker/page.tsx`、`app/ticker/[symbol]/page.tsx`、`app/search/page.tsx`、
